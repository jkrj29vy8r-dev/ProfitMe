# Mercedes-Benz

**Study:** serif display type against neutral UI sans, generous vertical rhythm,
restrained product cards, how a configurator-adjacent list stays calm at density.

**Watch for:** the serif/sans pairing carrying nearly all the hierarchy; how much
white space sits above a section title; the single saturated CTA color against an
otherwise achromatic page; filter/sort presented as one quiet control rather than
a filter bar.

**Do not lift:** the star mark, Mercedes' corporate typefaces, vehicle
photography, the blue CTA color.
