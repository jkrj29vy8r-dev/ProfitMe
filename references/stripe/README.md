# Stripe

**Study:** information density that stays readable, developer-facing UI, gradient
and light treatment, docs architecture, code presentation.

**Watch for:** how much can sit on one screen without feeling heavy; the layered
approach to depth (soft shadows, subtle borders, tinted surfaces); how technical
content is made to feel designed rather than dumped.

**Do not lift:** the signature gradient mesh, Stripe's illustration style,
component-for-component dashboard layouts.
