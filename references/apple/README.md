# Apple

**Study:** typographic hierarchy, negative space as a design element, scroll-driven
product narratives, photography treatment, the discipline of removing things.

**Watch for:** how few type sizes carry an entire page; how long a section is
allowed to breathe before the next one starts; how motion is used to reveal
rather than decorate.

**Do not lift:** SF/New York typefaces, product photography, headline copy,
signature layouts (the full-bleed hero-into-spec-grid sequence is theirs).
