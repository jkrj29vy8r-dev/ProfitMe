# Rimac

Dark, high-craft automotive. Currently the strongest motion reference in the
library.

**Study:** full-screen section transitions, the persistent numbered section index
as navigation *and* progress, wide-tracked uppercase display type, near-black
surfaces with photographic content bleeding through.

**Watch for:** the crossfade overlap between outgoing and incoming content; the
top-to-bottom stagger on menu items; the hamburger↔close icon morph; how little
chrome survives on screen; how legibility is preserved over photography without
a heavy scrim.

**Do not lift:** the shield mark, the numbered-index layout as a whole, section
imagery, the exact type treatment.
