# Spline

Dark developer/creative tool marketing — the closest reference in the library to
a SaaS product site.

**Study:** interactive hero that invites manipulation rather than just autoplaying,
elevated dropdown panels on dark surfaces, multi-column footer link architecture,
community/gallery grid density.

**Watch for:** how the dropdown panel separates from the page (border + subtle
lift, not a heavy shadow); the single accent used only for primary action; how an
interactive hero communicates its own affordance with one line of hint text.

**Do not lift:** the gradient orb mark, the blue accent, the 3D scene, the gallery
card layout.

**Note:** one capture shows a client-side error state on the live site. Useful as
a reminder that error states get designed too — not as a pattern to copy.
