# Vercel

**Study:** monochrome design systems, dashboard information architecture, empty
states, status and log surfaces, geometric restraint.

**Watch for:** how far a near-grayscale palette goes before color is introduced,
and what color is reserved *for*; border-and-radius consistency across every
surface; how deployment state is communicated at a glance.

**Do not lift:** the triangle mark, Geist, the black/white brand posture,
project dashboard layout.
