# Linear

**Study:** perceived speed, keyboard-first interaction, dark surfaces with
believable elevation, tight component spacing, purposeful micro-copy.

**Watch for:** transition durations short enough to feel instant but long enough
to read; how contrast is created in a dark UI without pure white; command palette
and shortcut affordances; empty and loading states treated as real design work.

**Do not lift:** the purple accent, Inter-with-their-exact-tracking, the issue
list layout, the marketing site's glow aesthetic.
